  • 2Recall is rarely the problem — faithfulness is. Most models find the evidence; fewer cite it cleanly and invent nothing. 13 of 16 models hallucinated at least once.
  • 3This is why the decision boundary is deterministic. A model producing evidence is a probability distribution; NomosGuard's gate consumes its claims through a hash-chained ledger and fail-closed rules — the model never decides.
Methodology — 4 scenarios with ground truth derived from raw logs before any model output was seen. Each model receives the identical prompt; outputs are scored by script on JSON validity, schema conformance, claim recall/precision, verbatim evidence citation, and hallucination count. All figures come from actual model runs (2026-10-09) via OpenCode Zen, Antigravity, and Vibe CLI — none are hand-computed. What this does not establish — performance on real production telemetry, robustness to adversarial prompt injection, or latency and cost at scale.
